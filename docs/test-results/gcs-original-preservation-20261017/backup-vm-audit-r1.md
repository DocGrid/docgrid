## 관측 결과

2026-10-17 약 01:40 KST에 첫 수동 검사를 시작해 **01:59:24 KST**에 완료했다. 이 회차는 감사 시작 시점의 목록을 검사했다. 원본 **95건**, 유효 보존본 **95건**의 크기·SHA-256 일치, retained **0건**, 오류 **0건**으로 성공했다. 비정상 시험 경로 사본 **2건**은 유효 경로에서 제외하고 `ignored_invalid_destination=2`로 표시했다. 원장은 **95건**, 원장·상태 파일 권한은 각각 `0600`이었다. 일별 timer는 `enabled`·`active`였다.

첫 전체 검사는 객체마다 CLI를 실행해 약 **19분** 소요됐다. 실행 중 새 시험 객체가 생성됐으므로 이 결과를 완료 시각의 모든 객체에 대한 감사로 해석하지 않는다. 새 객체와 반복 실행 시간은 [증분 검사 R2](backup-vm-audit-r2.md)에서 별도로 확인한다. DB·Barman 서비스 설정은 변경하지 않았다.
