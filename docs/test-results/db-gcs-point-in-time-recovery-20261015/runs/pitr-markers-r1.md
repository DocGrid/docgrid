- 목적·성공 기준: 한 run ID의 합성 쓰기 A와 B를 목표 시점 T 전후에 커밋하고, WAL을 보존해 복원 결과로 시점 선택을 판정한다.
- 위치·절차: 운영 Primary의 기존 시험 전용 `ha_probe_writes` 테이블에 A 입력 → 3초 대기 → T 기록 → 3초 대기 → B 입력. Barman `switch-wal --archive`, 기준 백업 manifest 재검증.
- 관측 시각: 2026-10-15 KST A 03:18:31.504713, T 03:18:34.510552, B 03:18:37.517245. WAL 교체·보관 확인 03:19:20~03:19:41 KST.
- 표본·결과: A 1건·B 1건 커밋. WAL 보관과 `verify-backup` 통과, 수신 프로세스 1개 확인.
