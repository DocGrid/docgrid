# DR-DB-GCS-REFERENCE-20261015-R1 — DB 참조와 백업 객체 대조

- 목적·성공 기준: 복원 시점 DB가 참조하는 GCS 객체를 독립 백업에서 모두 찾고 크기·바이트 해시 불일치가 0건이어야 한다.
- 위치·절차: 시험 DB의 `file_objects` 및 `document_versions.file_object_id` 관계를 읽고, 비공개 GCS 백업 원장의 객체 키·generation·크기·SHA-256과 대조.
- 시각: 2026-10-15 KST. 이 대조의 정확한 시작·종료 시각은 별도 캡처하지 않았다.
- 관측: GCS FileObject 91건·문서 버전 참조 96건, 백업 객체 92건. 참조 객체의 누락 0건, 버킷 불일치 0건, 크기 불일치 0건, SHA-256 불일치 0건. 나머지 백업 객체 1건은 FileObject 참조와 구분했다.
- 판정: **복원 DB 참조 대상의 백업 존재·바이트 일치 통과.** 백업 버킷 객체의 SHA-256은 별도 소스 복사 시험에서 실제 바이트를 읽어 계산했다. 앱 다운로드 API의 동작은 시험하지 않았다.
