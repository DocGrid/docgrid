# DR-BARMAN-UNIT-20261016-R1 — 로그 보존 실패

- 위치: 로컬 분리 작업 트리
- 목적: 감시기 정족수·전환 순서·실패 중단 단위 시험
- 방법: 단위 시험·Python 컴파일·diff 공백 검사를 호출한 뒤 결과 파일을 쓰려 했다.
