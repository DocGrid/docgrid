# DR-BARMAN-DBACCESS-20261016-R6 — 기존 인증으로 세 DB 노드 접속 확인

- 기록 시각: 2026-10-16 21:34 KST. 실행 시작·종료의 초 단위 시각은 수집하지 않았다.
- 목적·위치: GCP 백업 VM의 `barman` 계정에서 기존 인증 파일을 메모리로 읽고 각 DB 노드에 읽기 전용 `SELECT pg_is_in_recovery()` 실행
- 방법: GCP 인스턴스 목록에서 3개 노드를 메모리로 식별하고 SSH 표준입력으로만 주소를 전달했다. `barman list-server`로 서버 이름을 찾고 `show-servers <server>`의 현재 SQL 연결 설정과 인증 파일의 일치 항목을 사용했다. `PGPASSWORD`는 각 `psql` 자식 프로세스 환경에만 전달했다. 표준출력에는 접속 성공과 역할만 남겼다.
- 통과 기준: 3/3 접속, Primary 1대·Standby 2대, 인증 값·내부 주소 미기록, 임시 OS Login 키 제거
- 관측: 3/3 접속 성공. Standby 2대, Primary 1대. 원격 SSH 종료 코드 0. 임시 키 제거 명령 성공.
- 판정: **통과**. 기존 비밀번호가 세 DB 노드의 SQL 인증에 유효함을 확인했다. Barman의 지속 인증 파일에 세 노드 항목이 있다는 뜻은 아니며, 복제 연결·WAL 수신 연속성은 이 실행으로 확인하지 않았다.
