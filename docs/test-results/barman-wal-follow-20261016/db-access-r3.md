# DR-BARMAN-DBACCESS-20261016-R3 — 자동 승인 검토 거부

- 목적: Standby에서 실패한 백업 계정 인증 원인을 확인한 뒤 읽기 전용 SQL 접속을 재시험
- 위치·방법: 백업 VM의 비표준 자격증명 파일에서 기존 비밀번호를 읽어 메모리에서 재사용하는 명령을 제안했다.
- 통과 기준: 세 노드 접속, Standby 2·Primary 1, 비밀번호와 내부 주소 미기록
- 관측: **명령 실행 전** 자동 승인 검토가 거부했다. 비밀번호는 읽지 않았고 SQL 접속 재시험도 실행하지 않았다.
- 거부 이유: 비표준 자격증명 소스에서 비밀번호를 추출해 인증 실패 노드에 재사용하는 작업에 명시적 승인이 없음.
- 판정: **차단·미실행**. 인증 파일 변경과 Barman 모델의 실제 적용도 보류한다.
