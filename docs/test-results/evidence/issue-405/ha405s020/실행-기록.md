# 정상 쓰기 smoke 실행 기록

- 실행 ID: `ha405s020`
- 목적: GCP 내부 LB → 앱 A/B → OpenProxy A/B → OpenSQL primary의 합성 HTTP 쓰기 경로와 새 JWT·요청 원장 연결을 확인한다.
- 실행 위치: GCP 내부 k6 VM; 원장은 DB 밖의 격리된 로컬 시험 브랜치; DB 행은 현재 primary에서 읽기 전용 내보내기.
- 명령·부하: `run_ha_probe_k6.sh ha405s020 2 10s <내부 LB> <0600 단기 JWT> baseline-write`.
- 성공 기준: k6 201 응답 전건, 실패·결과 불명·드롭 0건, 201 ID별 DB 행 1개, 합성 계정 정리 타이머 3/3 유지.
- 실행 전 상태: 원장 `manifest.json`·`events.jsonl` 신규 생성; 독립 정리 타이머 3/3 무장 후 합성 계정 4명 생성. 토큰값·DB 계정 ID·내부 주소는 기록하지 않는다.
- 결과: **실행 준비 실패**. 원격 명령 종료 코드 127, k6 요청 **0건**. 부하 VM의 JavaScript·k6·0600 토큰은 존재했지만 runner 파일이 없어 k6가 시작되지 않았다. 성공 실행으로 집계하지 않는다.
- 조치: 저장소의 runner 파일만 암호화된 SSH로 전송하고 로컬·원격 SHA-256 일치를 확인했다. 재실행은 별도 ID `ha405s020b`로 기록한다.
