# 공개 증거 무결성·비식별 감사 — ha412-evidence-audit-01

- 목적: 네 GCP 실행의 원본 증거가 손상 없이 복원되고 공개본에 비밀·비공개 인프라 식별자가 없는지 검증.
- 위치: 로컬 독립 작업 트리, 2026-10-04 KST. 이 검사는 새로운 GCP 장애 시험이 아니다.
- 성공 기준: gzip/JSON 파싱 실패 0, Markdown 상대 링크 누락 0, 지정한 민감정보 패턴 탐지 0, k6 Point의 비어 있지 않은 tag 0, 원장·DB 대조 숫자 일치.

| 검사·명령 또는 방법 | 관측 결과 | 해석 |
| --- | ---: | --- |
| `gzip -t`로 실행별 모든 압축 증거 검사 | **20/20개 통과** | 압축 스트림 정상. 압축 전후 12개 원장 원본의 byte 동등성은 압축 당시 별도로 검사 |
| `jq -e 'type == "object"'`로 설정·요약·manifest·대조 JSON 확인 | **23/23개 통과** | JSON 구문·최상위 객체 형식 정상 |
| 각 `k6-metrics.jsonl.gz`의 `Point`를 다시 파싱해 tag 개수 계산 | Point **58,920 / 174,603 / 176,267 / 176,774**, 비어 있지 않은 tag **각 0개** | URL·계정·요청 ID가 k6 tag에서 노출되지 않음 |
| 공개 Markdown 상대 링크의 대상 존재 검사 | **14개 문서, 누락 0개** | 보고서에서 실행별 증거로 이동 가능 |
| 텍스트와 압축 텍스트에서 로컬 절대 경로·사설 IP·개인 계정 ID·PEM 시작·Bearer/JWT 패턴을 파일 이름만 출력하는 방식으로 검색 | **탐지 0개** | 검사한 패턴의 노출 없음. 임의의 모든 비밀 문자열을 수학적으로 배제하는 검사는 아님 |
| 실행별 `reconciliation.json`의 201/500·DB 행 수 필드 재조회 | 201 **4,200 / 12,366 / 12,474 / 12,516건**; 장애 500 **68 / 88 / 85건**; 201 누락·중복 각 **0건** | 집계 표가 외부 원장·DB 대조와 일치 |
| 공개 증거 크기 `du -sk` | 약 **6,168 KiB** | 원본 k6 Point를 무손실 gzip으로 보존. Git 기록 자체는 삭제하지 않음 |

민감정보 검색은 기록된 내용을 출력하지 않고 파일명만 반환하도록 했다. 원격 VM의 별도 원본 증거는 이 로컬 공개본 감사 대상이 아니며, 이 문서는 VM이 중지·삭제됐다는 뜻이 아니다.
공개용 파생 CSV 8개는 Git 공백 검사에 맞게 줄 끝의 CRLF만 LF로 정규화했다. 원시 k6 Point·외부 원장·DB 대조의 gzip 원본은 이 단계에서 바꾸지 않았다.
