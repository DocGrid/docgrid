# issue378-k6-inspect-20261002-01 — 공식 k6 런타임 첫 검사

| 항목 | 기록 |
| --- | --- |
| 실행 위치 | 로컬 Docker, 공식 `grafana/k6:2.3.0` 이미지 |
| 목적 | STOMP 부하 스크립트 초기화·옵션 파싱 |
| 명령 | `k6 inspect k6_dashboard_load.js` (합성 토큰 파일만 사용) |
| 성공 기준 | 종료 코드 0 |
| 결과 | **실패**, 종료 코드 107. `inspect`는 기본적으로 시스템 환경 변수를 전달하지 않아 토큰 파일 경로가 비었음 |
| 해석 | 스크립트 문법·실측 실패가 아니라 `inspect` 명령의 환경 변수 정책. 공식 문서의 `--include-system-env-vars`로 재실행 |
