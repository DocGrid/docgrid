관측 VM의 과거 대시보드 원본은 0600 롤백용 백업으로 보존했다. 관리자 비밀번호·사설 IP·토큰을 API 결과·이 문서·저장소에 기록하지 않았다. Grafana는 같은 기존 IAP 터널과 인증된 사용자 화면에서 확인했고 외부 공개 포트는 추가하지 않았다.
적용에 사용한 관측 VM의 임시 JSON·스크립트 파일과 임시 OS Login 키는 확인 후 제거했다. 기준선 카드 값은 실행 후 약 10분간 현재 화면에서 조회할 수 있고, 이후에는 해당 실행의 **고정 시간 범위**를 선택해야 한다. 이는 누적값이 삭제된 것이 아니라 카드 쿼리의 10분 lookback 경계다.
