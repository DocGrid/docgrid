# 공개 화면 PDF 사용자 흐름 — `ui471-http-r1`

- 목적: 실제 Vercel 화면에서 가입·로그인·업로드·인덱싱 표시·검색·다운로드를 확인한다.
- 위치: 공개 브라우저 화면, GCP 앱 A/B·OpenSQL·GCS·CPU 임베딩 서버. 2026-10-10 약 05:10~05:20 KST.
- 기준: `test/471`의 `d28c202f01251a945410ef6598be8cfb48671d5e` 기반 코드. 시험 계정은 일반 USER, PDF는 합성 본문만 포함한다.
- 성공 기준: 업로드 수락, 시험 문서 최종 `INDEXED`, 검색 노출, 다운로드 SHA-256이 원본과 같음. RAG 답변·WebSocket은 별도 판정.

| 순서·실행 위치 | 실제 조작·명령 | 관측 결과 | 판정 |
| --- | --- | --- | --- |
| 1. 공개 브라우저 | 시험 계정 가입·로그인 | 최초 비밀번호 72자 입력은 화면의 12~64자 제한으로 거부; 50자 시험 비밀번호로 가입·로그인 성공 | 재시도 후 통과. 자격증명 원문은 기록하지 않음 |
| 2. 공개 브라우저 | `＋ 문서 업로드` → 파일 선택 → 합성 PDF 1개, PRIVATE, 제목 입력 | 화면 알림 `문서 #115 업로드가 접수됐습니다. Job #116`; 상세 화면은 처음 `UPLOADED`·Job `PENDING` | 업로드 수락 |
| 3. 공개 브라우저 | 문서 상세 새로고침 | 중간에 헤더 `INDEXING`과 버전 `INDEXED`가 한 화면에 함께 보였고, 다음 조회에서 문서·v1 모두 `INDEXED`, 처리 중 버전 없음 | 최종 수렴 통과; 중간 표시 불일치의 원인은 미확정 |
| 4. 공개 브라우저 | `amber observatory circuit` 검색 | 2개 결과 중 시험 문서 #115가 1위·유사도 60.1%; 다른 공유 문서의 본문은 기록하지 않음 | 검색 통과 |

| 6. 공개 브라우저 | 검색 결과의 비동기 답변 표시 확인 | `답변 생성 중` 뒤 `AI 생성 실패·검색 결과 저장됨`; 검색 결과 자체는 유지 | RAG 답변은 실패, 검색 성공과 섞지 않음 |

브라우저의 숨김 파일 input 직접 클릭은 시간 초과였다. 보이는 파일 선택 라벨을 눌러 file chooser에 같은 PDF를 지정해 완료했다. 시험 계정 정보·JWT·내부 주소·다른 문서의 원문은 로그에 남기지 않았다.
