# 인증 WebSocket 첫 연결 — `ws471-r1`

- 목적: 공개 WSS에서 JWT 인증 `CONNECTED`·개인 RAG 구독·실제 메시지를 분리 판정한다.
- 위치: 로컬 Node WebSocket 부하, 공개 Cloud Run 진입점, GCP 앱 A/B. 2026-10-10 약 05:21 KST.
- 방법: 임시 로컬 스크립트로 `CONNECT`(시험 JWT, `heart-beat:0,0`) → `SUBSCRIBE /user/queue/rag-answer` → 검색 HTTP POST. 토큰·프레임 본문은 기록 전 제외한다.
- 기준: `MESSAGE` 1개 이상을 받아야 완전 통과한다.

| 관측 | 결과 | 해석 |
| --- | --- | --- |
| 인증 연결 | `CONNECTED=true` | 공개 WSS 업그레이드·STOMP 인증 통과 |
| 구독 | `SUBSCRIBE` 프레임 전송, receipt 미수신 | 등록 완료를 receipt로 확인하지 못함 |
| 검색 | HTTP 200 | 검색 API 통과 |
| 알림 | `MESSAGE=0`, 약 31.6초 뒤 socket error | 완전 E2E 실패. heartbeat 부재가 유휴 종료에 기여했을 가능성은 있으나 이 실행만으로 원인 확정 불가 |

Cloud Run 요청 로그의 `/ws/websocket` 상태는 101, 연결 길이는 31.565657초였다. 이 101은 알림 프레임 수신을 뜻하지 않는다.
