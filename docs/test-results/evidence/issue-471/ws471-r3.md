# heartbeat 유지·알림 재시험 — `ws471-r3`

- 목적: 유휴 종료와 RAG 알림 미수신을 분리한다.
- 위치: 로컬 Node → 공개 WSS·HTTP. 2026-10-10 약 05:29 KST.
- 방법: STOMP `heart-beat:10000,10000`, 클라이언트 10초 heartbeat, `SUBSCRIBE` 후 1초 대기→검색 POST, 최대 90초 관측.

| 관측 | 결과 | 해석 |
| --- | --- | --- |
| 인증·요청 | `CONNECTED=true`, SUBSCRIBE 전송, 검색 HTTP 200 | 공개 경로의 인증·검색은 동작 |
| 연결 | 클라이언트 heartbeat 8회, Cloud Run 101 연결 89.835725초 | 앞선 31초 종료는 heartbeat 없는 시험 클라이언트와 관련됐다는 관측 |
| 구독·알림 | receipt 0, MESSAGE 0 | 90초 살아 있어도 알림 수신을 증명하지 못함 |

원인 후보에는 구독 미등록, RAG 작업 완료 시점, 백엔드 A/B의 로컬 브로커 경계가 있다. 이 실행으로 하나를 확정하지 않는다.
