# 공개 HTTP PDF·RAG E2E — `rag478-public-e2e-r1`

- 목적: GCP 전용 CPU Ollama VM의 Qwen 2.5 7B를 앱 A/B가 사용해 실제 공개 API에서 PDF 인덱싱·검색·답변 생성까지 완료하는지 확인한다.
- 실행 위치·시각: 로컬 비밀 미보존 시험 클라이언트 → Vercel 공개 API → GCP 앱 A/B·BGE-M3·OpenSQL·GCS·Ollama, 2026-10-10 03:18~03:23 UTC.
- 실행 개정: 앱 A/B의 시험 배포 JAR. 이 실행의 앱 JAR 해시는 별도 캡처하지 못했다. 후속 지표 배포 전 결과이며, 새 지표 코드의 실측으로 혼동하지 않는다.
- 방법: 합성 PDF 1건 업로드 → 해당 버전으로만 제한한 인덱싱 Worker 활성화 → 상태 조회 → 공개 검색 → 비동기 답변 재조회. 시험 계정 비밀번호·JWT·답변 본문은 프로세스 메모리 밖에 기록하지 않았다.
- 성공 기준: 업로드 HTTP 201, 문서 `INDEXED`, 검색 HTTP 200과 결과 1건 이상, RAG `SUCCESS`와 비어 있지 않은 답변·인용. 브라우저 화면의 렌더링은 이 실행의 기준이 아니다.

원본 실시간 출력은 시험 터미널에서 관측했지만 이 파일은 종료 후 작성한 **비식별 결과 요약**이다. 원본 터미널 스트림을 실시간 파일로 저장했다고 주장하지 않는다. API 응답의 의미적 정답 여부, 브라우저 화면 렌더링, WebSocket 수신, 장기 처리량은 이 실행에서 판정하지 않았다. 7B CPU의 답변 완료를 한 건 관측했으나 모든 문서가 같은 시간에 끝난다는 보장은 아니다.
