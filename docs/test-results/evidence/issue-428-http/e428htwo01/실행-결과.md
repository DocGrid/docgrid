Patroni 컨테이너 로그에서 `failsafe` 키워드를 **27건** 관측했다(첫 시각 07:18:26.889, 마지막 07:19:47.772 UTC). 원본 로그에는 공개하면 안 되는 인프라 식별자가 포함될 수 있어 원문은 반출하지 않았다. 역할 REST API는 중단 중에도 조회했지만 각 표본의 정확한 UTC 시각을 함께 저장하지 못했다. 따라서 **전체 구간에 걸친 단일 primary의 연속 증거라고 주장하지 않는다.** 전후에는 primary 1대·streaming replica 2대였다.

실행 종료 뒤의 수동 `recover`는 가드가 이미 자동 재개한 상태에서 멱등적으로 실행됐다. 복구 시각은 수동 명령 시각이 아니라 위 **첫 자동 재개 journal**로 판정한다. k6 stderr도 민감정보 제거가 보장되지 않아 수집하지 않았다.
