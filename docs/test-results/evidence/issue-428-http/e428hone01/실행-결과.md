한 멤버 중단 중 `etcdctl endpoint health` 직접 조회는 자동 가드가 이미 재개한 **뒤** 실행돼 3/3으로 보였다. 따라서 그 조회를 장애 중 2/3의 직접 측정으로 제시하지 않는다. PID 일시정지·재개 시각과 HTTP 요청 결과는 별도 기록이다. k6 stderr는 민감정보 사전 제거가 보장되지 않아 수집하지 않았다.
