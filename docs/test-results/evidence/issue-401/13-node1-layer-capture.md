# #401 첫 replica 실행 계층 캡처

- 실행 ID: `issue-401-node1-capture-01`
- 목적: 기본 Rocky 이미지에 없는 기존 패키지·설정을 로컬 전용 이미지에 보존하고, 이후 `--init` 컨테이너의 입력을 고정한다.
- 실행 위치: GCP DB replica VM node1. DB 데이터 bind mount는 이미지에 포함하지 않는다.
- 절차: 수정 스크립트의 해시 검증·root 설치 → 기존 컨테이너 계약 확인 → `docker commit --pause=false`로 노드 전용 로컬 이미지 캡처 → 이미지·기존 컨테이너 상태 확인.
- 성공 기준: 클러스터와 현재 DB 컨테이너 변경 0건, 새 로컬 이미지 1개, 이미지 환경 변수 계약 유지. 저장소/registry push 0건.
- 결과: 도우미 설치 **1/1**, 로컬·원격 SHA-256 일치 **1/1**. 기존 컨테이너 계약을 통과해 로컬 전용 이미지 캡처 **1/1**, 원래 DB 컨테이너는 계속 실행 중이다. Registry push **0건**.
- 판정: 이미지 생성까지 통과. 해당 이미지에서 서비스 의존성과 PID 1 init이 함께 동작하는지 별도 후보 시험이 필요하다.
