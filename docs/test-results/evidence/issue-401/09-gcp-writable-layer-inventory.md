# #401 기존 writable layer 안전 목록

- 실행 ID: `issue-401-writable-layer-inventory-01`
- 목적: 기존 DB 컨테이너가 기본 Rocky 이미지에 없는 실행 의존성을 overlay에 갖는지 확인하여 재생성 시 이미지 보존 방식을 정한다.
- 실행 위치: GCP DB replica VM의 기존 컨테이너와 분리된 임시 기본 이미지 컨테이너.
- 절차: 두 이미지의 RPM 패키지 이름 집합 크기·차이 개수와 `docker diff` 변경 경로의 최상위 범주별 개수만 계산. 경로·파일 내용·환경 변수는 기록하지 않는다. 임시 컨테이너는 종료 후 삭제한다.
- 성공 기준: 차이가 있는지 정량 판정, 임시 컨테이너 삭제 1/1, 기존 DB 컨테이너 변경 0건.
- 결과: 기존 컨테이너 RPM **168개**, 기본 이미지 **147개**. 기존 쪽에만 **21개** 추가됐고 기본 쪽에만 있는 것은 **0개**. 기존 컨테이너의 Docker overlay 변경 항목 **2,648개**. 임시 후보 삭제 **1/1**, 운영 DB 변경 **0건**.
- 판정: 기본 이미지 재생성은 실행 환경을 잃으므로 안전하지 않다. 기존 컨테이너의 writable layer까지 보존하는 로컬 이미지 또는 동등한 재설치 절차가 필요하다.
