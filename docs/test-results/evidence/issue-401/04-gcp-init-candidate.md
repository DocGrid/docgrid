# #401 GCP Rocky 컨테이너 init 후보 시험

- 실행 ID: `issue-401-gcp-init-candidate-01`
- 목적: 운영 데이터 마운트와 Patroni를 건드리지 않고 현재 이미지에서 Docker `--init`의 PID 1 및 고아 자식 회수 동작을 확인한다.
- 실행 위치: GCP DB replica VM 한 대의 Docker 호스트. IAP/만료형 임시 SSH 키 사용.
- 절차: 다른 이름의 임시 컨테이너를 `--init`로 실행 → `docker inspect`와 컨테이너 내부 `ps` 조회 → 짧게 생존하는 고아 자식 생성 → 좀비 수 확인 → 정확한 임시 컨테이너 삭제.
- 성공 기준: PID 1이 `docker-init` 또는 `tini`, init 플래그 true, 고아 자식이 좀비로 남지 않음, DB 컨테이너와 데이터 마운트는 변경 0건, 임시 컨테이너 정리 1/1.
- 1차 실행: 종료 코드 **127**, 계측 출력 없음. 실패 지점과 임시 컨테이너 정리 상태를 아직 확인하지 못했으므로 이 실행은 **실패/결과 불명**으로 보존한다. IAP 접속과 `sudo`·`docker`·`jq`·`bash` 명령 존재는 별도 읽기 전용 명령으로 4/4 확인했다.
- 다음 조치: 후보 컨테이너 잔존 여부 확인 후 단계별 상태 표시를 넣어 재실행. 원인을 모르는 동안 DB 컨테이너를 교체하지 않는다.
