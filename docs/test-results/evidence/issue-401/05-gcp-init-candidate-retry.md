# #401 GCP Rocky 컨테이너 init 후보 재시험

- 실행 ID: `issue-401-gcp-init-candidate-02`
- 목적: 1차 후보 시험의 종료 코드 127 위치를 특정하고, 같은 이미지에서 `--init` 동작과 정리를 다시 검증한다.
- 실행 위치: GCP DB replica VM 한 대의 Docker 호스트.
- 절차: 이전 후보 잔존 여부 확인 → 단계별 상태 표시 → 격리된 임시 컨테이너 기동·PID 1·고아 자식·정리 확인.
- 성공 기준: 이전 후보 0개, 새 후보 PID 1 init/좀비 0개, 임시 후보 정리 1/1, 운영 DB 컨테이너 변경 0건.
- 결과: 이전 후보 **0개**, 새 후보 실행 성공(`run=1`), `inspect` 단계에서 **종료 코드 127**. 오류 트랩이 후보를 제거했다. 이미지에 진단 명령이 없는지 분리 확인해야 하므로 PID 1·좀비 수는 **미측정**.
- 해석: 이 결과는 Docker `--init` 실패가 아니라 후보 이미지의 명령 가용성 또는 검사 파이프라인 문제다. 운영 DB 변경은 0건. 다음 실행에서 `/proc`와 호스트의 `docker top`을 이용한다.
