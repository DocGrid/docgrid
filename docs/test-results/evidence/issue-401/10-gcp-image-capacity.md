# #401 로컬 이미지 보존 전 디스크 용량 확인

- 실행 ID: `issue-401-image-capacity-01`
- 목적: 기존 컨테이너 writable layer를 로컬 이미지로 보존해도 DB VM 디스크가 가득 차지 않는지 확인한다.
- 실행 위치: GCP DB VM 3대의 Docker 호스트.
- 절차: 루트/데이터 파일시스템 여유와 각 DB 컨테이너의 `SizeRw`를 숫자·단위로 조회한다. 경로·디스크 이름·주소는 기록하지 않는다.
- 성공 기준: 3대 모두 사용 가능한 공간이 writable layer보다 충분히 큼. 부족한 노드에서는 이미지 캡처·컨테이너 교체를 중단한다.
- 결과: node1 writable layer **444,383,232 B**, Docker 파일시스템 여유 **25,842,556,928 B**; node2 **389,574,656 B / 26,067,001,344 B**; node3 **392,536,064 B / 26,065,788,928 B**.
- 판정: 세 노드 모두 계층 크기의 50배 이상 여유가 있어 로컬 이미지 한 개를 보존할 용량은 충분하다. 이는 디스크 snapshot의 복구 가능성이나 이미지 내부 비밀 부재를 검증한 것은 아니다.
