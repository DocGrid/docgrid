# #401 두 번째 replica 실행 계층 캡처·격리 확인

- 실행 ID: `issue-401-node3-capture-01`
- 목적: node3 고유 writable layer를 local-only 이미지로 보존하고 `--init` 후보에서 의존성과 고아 자식 회수를 확인한다.
- 실행 위치: GCP node3 DB VM, 데이터 마운트가 없는 임시 후보 컨테이너.
- 절차: 도우미 해시 검증·root 설치 → 기존 컨테이너 캡처 → 캡처 이미지 후보의 init/PID 1/RPM·도구/좀비 확인 → 후보 삭제.
- 성공 기준: 도우미 해시 일치, 캡처 이미지 1, 기존 대비 RPM 수 일치, 후보 init=true·좀비 0, 후보 삭제 1/1, 기존 DB 무변경.
- 결과: 도우미 설치 및 SHA-256 일치 **1/1**. 로컬 전용 실행 계층 캡처 **1/1**. 격리 후보 `Init=true`, PID 1 `docker-init`; 기존/캡처 이미지 RPM **168/168개**, `ps`·`jq` **2/2**, 종료 자식 좀비 **0개**, 후보 삭제 **1/1**. 기존 DB 컨테이너 변경 **0건**.
- 판정: node3도 교체 입력 준비 완료. 실제 서비스 재합류는 다음 실행에서 판정한다.
