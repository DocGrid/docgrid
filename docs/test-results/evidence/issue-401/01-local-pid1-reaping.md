# 컨테이너 PID 1의 종료 자식 정리 비교

- 실행 ID: `issue401-pid1-01`
- 시작: 2026-10-03 18:32 KST
- 목적: `sleep`을 PID 1로 둔 컨테이너와 Docker `--init` 컨테이너에서 고아 프로세스 종료 후 좀비 잔여가 다른지 확인한다.
- 위치: 로컬 Docker Engine, 설치된 `alpine:latest` 이미지, 폐기 가능한 시험 컨테이너 2개. GCP DB 노드는 건드리지 않는다.
- 방법: 각 컨테이너 안에서 짧은 자식 프로세스를 만든 뒤 부모 셸을 종료하고, 1초 후 프로세스 상태의 `Z` 개수를 센다.
- 성공 기준: 대조군의 좀비 잔여 여부와 `--init`군의 잔여 여부를 각각 숫자로 기록하고 두 컨테이너를 제거한다. 이 시험은 실제 Patroni 재합류 성공의 증거가 아니다.

| 군 | 자식 종료 1초 후 좀비 수 | 해석 |
| --- | ---: | --- |
| PID 1=`sleep`, `--init` 없음 | **1개** | 종료한 고아 자식이 PID 1 아래에 남았다. |
| Docker `--init`, 주 프로세스=`sleep` | **0개** | init 프로세스가 고아 자식을 정리했다. |

- 시험 명령 종료 코드: **0**. 시험 컨테이너 **2/2 제거**를 재확인했다.
- 판정: **로컬 가설 재현 성공**. 다만 Alpine의 짧은 자식 프로세스 사례이며, OpenSQL·Patroni의 실제 강등 경로를 재현한 것은 아니다.
