# #401 현재 primary의 실행 계층 캡처·후보 확인

- 실행 ID: `issue-401-node2-capture-01`
- 목적: primary를 옮기기 전에 node2 기존 실행 계층을 보존하고 `--init` 후보의 의존성과 자식 회수를 검증한다.
- 실행 위치: GCP node2 DB VM의 기존 컨테이너(읽기/이미지 캡처)와 데이터 마운트 없는 임시 후보.
- 절차: 도우미 설치·해시 일치 → `docker commit --pause=false` → 캡처 이미지 후보의 RPM·PID 1·좀비·정리 확인.
- 성공 기준: 기존 primary 중단 0건, 캡처 이미지 1, 이미지 후보 init=true·RPM 동일·좀비 0·삭제 1/1.
- 결과: 도우미 설치와 해시 일치 **1/1**, local-only 이미지 캡처 **1/1**. 격리 후보 `Init=true`, PID 1 `docker-init`, 기존/후보 RPM **168/168개**, `ps`·`jq` **2/2**, 좀비 **0개**, 후보 삭제 **1/1**. 기존 primary 중단 **0건**.
- 판정: node2도 교체 입력 준비 완료. 역할 이전과 실제 DB 재합류는 다음 실행에서 판정한다.
