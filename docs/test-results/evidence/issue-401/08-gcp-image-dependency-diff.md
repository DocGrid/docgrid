# #401 기존 컨테이너·기본 이미지 실행 의존성 비교

- 실행 ID: `issue-401-image-dependency-diff-01`
- 목적: 기본 Rocky 이미지로 컨테이너를 다시 만들 때 기존 writable layer의 패키지·바이너리가 사라지는지 확인한다.
- 실행 위치: GCP DB replica VM의 기존 컨테이너와 분리된 임시 기본 이미지 컨테이너.
- 절차: 동일한 명령 이름의 `command -v` 존재 여부를 두 컨테이너에서 Boolean으로만 비교하고 임시 컨테이너 삭제. 바이너리 경로·환경 변수·설정 원문은 기록하지 않는다.
- 성공 기준: 차이를 식별하고 새 컨테이너 구성에서 모든 필수 실행 의존성을 보존할 계획을 확정; 임시 컨테이너 정리 1/1, 운영 DB 변경 0.
- 결과: 기존/기본 이미지에서 `ps` **1/0**, `jq` **1/0**. `python3`·`dnf`·`awk`는 양쪽에 있고, `patroni`·`etcd`·`psql` 등의 실행 파일은 양쪽 기본 `PATH`에 없다(제품 자체의 설치 경로는 별도). 임시 컨테이너 정리 **1/1**, 운영 DB 변경 **0건**.
- 판정: 기본 이미지에서 즉시 재생성하는 현재 코드만으로는 기존 writable layer와 동등하다고 주장할 수 없다. 필요한 설치 패키지와 저장 위치를 추가 비교하기 전에는 라이브 교체를 **중단**한다.
