DB 전용 CSV는 **12,992행(헤더 포함)**, SHA-256 `0c0c267b20f1be98843dab1e08899d4745e223e81e2b31b7592e1e655f7b6a86`이다. 원본은 각 VM의 보호된 실행별 위치에 있고, 후속 작업에서 검증한 안전 사본만 실행별 증거로 반출했다. 별도 **새 A/B 계측 실행**은 `ha391fa20001`·`ha391fb20001`이다.

초기에는 B 전용 로컬 증거 반출이 안전 검토에서 두 번 거부되어, **그 시점에는** 외부 원장·ID join을 완료하지 못했다. 후속 작업에서 B 전용 목적지와 원본 2개 SHA-256, 기존 A 자료의 SHA-256 불변을 다시 확인한 뒤 허용 필드 이벤트와 ID·행 수 전용 DB CSV만 반출했다. `ha_evidence.py import-k6 → finish → verify`와 `reconcile_ha_probe.py`를 수행했고, **13,001개 클라이언트 ID 중 12,991개 201이 DB 1행과 정확히 일치, 500 10개는 DB 미반영**이다. 대조 명령은 HTTP 500 때문에 종료 코드 **2**를 반환한다. 이는 내구성 불일치가 아니라 정상 기준선 실패를 뜻한다.
