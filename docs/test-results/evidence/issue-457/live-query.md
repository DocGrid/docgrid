# fix457-live-query-01 — 기존 실행의 Prometheus 쿼리 재측정

- 기록 시각: 2026-10-10 02:12 KST. 실행 당시 정확한 조회 시작 시각은 수집하지 못했다.
- 목적·위치: GCP 관측 VM 내부 Docker 네트워크의 Prometheus에서 기존 `ha1009163528` 시계열을 읽기 전용 조회. 새 k6·장애 실행은 하지 않았다.
- 방법: Prometheus `/api/v1/query_range`에서 원시 `k6_ha_outcome_500_total`과 새 `sum(last_over_time(...[10m])) or VU*0` 쿼리를 절대 시간 범위로 조회. 주소·인증값은 기록하지 않았다.
- 성공 기준: 500 누적값이 첫 오류 전 0, 첫 Counter 수신 이후 1이고 이후 유지.
- 결과: 원시 500 Counter는 **11개 표본**이 저장됐고 모두 값 1. 첫 표본은 **2026-10-10 01:38:40 KST**. 새 쿼리는 5초 간격 조회에서 **01:38:20~35의 0 → 01:38:40~55의 1**을 반환했다.
- 해석: 이전 그래프가 희미했던 이유를 “원시 표본이 한 개뿐”으로 단정할 수 없다. 첫 표본이 이미 1이므로 `rate()`는 그 이전 증가를 계산하지 못한다. 조회 해상도와 Remote Write 주기로 오류 완료 시각과 최대 수초 차이 날 수 있다.
