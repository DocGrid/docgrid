# 전체 ID k6 재전송 — 부하 VM 무장애 스모크 기록

환경: GCP 내부 부하 VM의 k6 2.3.0, 내부 LB를 통한 시험 전용 멱등 HA probe. 실제 VM 장애는 주입하지 않았다. 계정·JWT·내부 주소·프로젝트 식별자는 이 기록에 넣지 않았다.

| 기록 | 목적 | 관측 결과 | 판정 |
| --- | --- | --- | --- |
| [최초 쓰기 r01](initial-r01.md) | 새 ID의 무장애 201·DB 1행 확인 | 10개 ID, 201 10건, 미전송 0, 사전 DB 10행 | 통과 |
| [전체-ID 재전송 r01](replay-r01-failed.md) | 같은 ID를 실제 k6로 재전송 | 스크립트 초기화 오류 107, HTTP 재전송 0건 | 실패·원본 보존 |
| [수정본 루프백 r01](loopback-r01.md) | 수정본을 실제 k6 2.3.0으로 로딩·실행 | 루프백 10회 시도, 원장 20이벤트, 요약 생성, 미전송 0 | k6 실행 경로 통과. 실제 DB 계약은 미검증 |

첫 재전송 실패는 숨기지 않는다. 수정 PR을 머지하고 부하 VM 배포를 다시 검증한 뒤, 새 실행 ID·새 합성 계정으로 201→200 및 DB ID별 1행 시험을 별도로 반복한다.
