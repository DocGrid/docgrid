# GCP Outbox 시험 전 VM 상태 조회

- 실행 ID: `outbox439-gcp-01`
- 실행 시각: 2026-10-05 약 21:00 KST
- 환경: GCP Cloud Console VM 목록, 읽기 전용 조회
- 목적: 실제 Outbox 소비 시험에 필요한 DB/앱/캐시의 기동 상태 확인
- 성공 기준: 역할별 VM 실행 수를 확인하되, VM 상태를 게스트 내부 서비스 상태로 혼동하지 않음
- 방법: VM 목록의 상태 표시를 역할별로 집계. 프로젝트 ID, VM 이름, IP는 기록하지 않음

| 역할 | 실행/전체 | 판정 |
| --- | ---: | --- |
| DB 노드 | **3/3** | VM만 실행 확인. Patroni/Outbox 테이블은 미조회 |
| 백엔드 A/B | **0/2** | 현재 앱 Dispatcher 소비 경로는 정지 상태 |
| 공용 캐시 | **0/1** | 앱 재기동 전에 구성·기존 이벤트를 먼저 확인해야 함 |
| 부하 발생기 | **0/1** | 이번 읽기 전용 기준선에는 필요 없음 |

경고: VM 실행 상태만으로 DB 서비스 건강, Outbox 대기량, Dispatcher 설정 적용 여부를 알 수 없다. 따라서 앱/캐시 VM은 시작하지 않았고, Dispatcher를 켜지 않았으며, 시험 이벤트 생성과 장애 주입은 **0건**이다. 정리·원복할 변경도 없었다.
