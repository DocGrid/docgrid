# B 기동 시험 데이터 시각 오류 — run-b-start-02

| 항목 | 기록 |
| --- | --- |
| 목적 | A가 모델 응답을 기다리는 동안 B를 기동해 같은 작업의 호출 횟수를 관찰 |
| 시각·위치 | 2026-10-16 05:46:12~05:46:26 KST, 로컬 격리 PostgreSQL·백엔드 JVM A/B·제어 모델 서버 |
| 방법 | A 기동 → 합성 RAG 행 1건 삽입 → 모델 호출 1회 보류 → B 기동 → DB 상태 조회 |
| 성공 기준 | B 기동 뒤 호출 1회와 `PROCESSING` 유지, 응답 해제 뒤 `SUCCESS` |
| 관측 | B 준비 후 호출은 1회였지만, 05:46:25에 DB 상태가 `FAILED`가 됨 |
| 결과 | 불합격. 시험 행의 `created_at`을 DB UTC 시각으로 넣어 앱의 로컬 시각 기준 스위퍼가 오래된 작업으로 판정할 수 있는 구성 오류가 있음 |
| 정리 | 시험 행 1건 삭제, A/B와 모델·임베딩 시험 서버 종료 |

시각 원인은 시험 SQL과 앱의 시간 계산을 대조한 해석이다. 이 실행만으로 코드의 lease 동작을 판정하지 않고, 시험 행을 앱 기준 KST로 만든 새 실행에서 재검증했다.
