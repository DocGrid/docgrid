# 변경 코드 자체 검토

작성자가 실제 변경 diff·사용 지점·최종 실행 증거를 대조한 기록이다. 독립 리뷰어나 GitHub APPROVED 판정으로 표현하지 않는다.

| 확인 항목 | 검토 결과·근거 |
|---|---|
| 새 조회의 권한 | 답변·대화 소유권 뒤 고유 문서 출처를 Primary에서 재인가. 회수 문구가 두 GET에서 각각 0/3회 |
| 모델 전송 | 저장 promptText 재사용 제거. 현재 허용 후보·과거 문맥으로 재구성하며 queued/history 회귀 통과 |
| 전이적 출처 | 모델에 사용한 이전 답변 출처까지 합집합 기록. 현재 인용만으로 권한을 추정하지 않음 |
| 출처 불명 | NULL·손상 JSON·잘못된 ID는 허용으로 추정하지 않음. 기존 행 삭제·불확실한 역산 없음 |
| 모델 처리 중 회수 | 저장 전 재인가 후 안전 안내만 조건부 확정. 성공·오류 응답 두 경로 통과 |
| timeout 경계 | 예전 검색 1위와 새 출처가 달라질 수 있어 보완. 현재 후보의 fallback·실제 출처를 원자 갱신하고 별도 HTTP 회귀 통과 |
| 작업 소유권 | 새 prompt/source UPDATE도 PROCESSING·token·유효 lease 조건. 기존 완료 fencing 유지 |
| 트랜잭션 | 외부 모델 대기 밖으로 준비/확정을 분리. 응답 보류 두 회차 idle in transaction 각각 0개 |
| CI | 전용 DB·Redis DB에서 동일 9개 HTTP 경계를 별도 Gradle 작업으로 실행. 기본 회귀와 격리 |
| 증거·보존 | 최종 기본 회귀와 HTTP의 운영 소스·리소스·build 파일 554개 해시가 현재 파일과 모두 일치. 민감정보·상대 링크 검사 0건 |

자체 검토 뒤 미해결로 확인한 차단 결함은 없다. 외부 전송과 권한 회수 커밋의 원자성, 이미 전송한 내용의 소급 회수, 실제 Ollama·OpenSQL HA·공개 배포는 이번 검증 범위가 아니다. 별도 PR CI와 diff 검토 결과는 PR에 남긴다.
