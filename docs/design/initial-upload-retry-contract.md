# 최초 문서 업로드의 결과 불명 재시도 계약

상태: **제안**. 이 문서는 현재 API와 후속 멱등 처리의 목표 계약을 구분한다. 아래 `Idempotency-Key` 동작은 아직 구현되지 않았다.

## 현재 API와 관측된 경계

`POST /api/documents`는 인증된 사용자의 `multipart/form-data`에서 `file`, `title`, `description`, `visibility`를 받는다. 성공 시 HTTP 201과 `documentId`, `documentVersionId`, `fileObjectId`, `embeddingJobId`, `documentStatus`, `jobStatus`를 반환한다. 현재 요청 키나 결과 조회 키는 없다.

`DocumentUploadFacade`는 같은 파일 해시·크기의 `FileObject`를 재사용할 수 있지만, 이것은 **바이너리 중복 제거**다. 동일 HTTP 요청의 재전송인지 판정하지 않으며 문서·버전·Outbox·Job을 새로 만들 수 있다. 파일 저장소 후보는 DB 트랜잭션 전에 생성된다. DB 저장의 `RuntimeException`은 후보 삭제를 시도하지만, 프로세스가 저장 직후 중단되면 그 코드가 실행되지 않는다.

```text
현재 최초 업로드
  클라이언트 POST
    → 파일 검증·SHA-256 계산
    → 기존 FileObject 조회
    → 없으면 저장소 후보 생성
    → DB 트랜잭션: 문서·버전·Outbox·Job 기록
    → HTTP 201 반환

결과 불명: DB 커밋 후 응답 유실 → 사용자는 재전송 여부를 결정할 근거가 없음
중단 경계: 저장소 후보 생성 후 앱 종료 → DB 참조와 보상 삭제가 모두 없음
```

로컬 기준선의 실제 관측값과 모의 범위는 [`docs/test-results/upload-ambiguity-baseline-20261013/README.md`](../test-results/upload-ambiguity-baseline-20261013/README.md)에 기록한다.

## 후속 구현의 목표 계약

클라이언트는 **한 번의 사용자 업로드 의도**에 키 하나를 만들고, 결과 불명 재시도에서 같은 키와 같은 입력을 유지한다. 단계적 배포 중 키가 없는 기존 요청은 현재 동작을 유지한다. 키가 있는 요청에 대해서는 인증 사용자·작업 종류·대상 문서·키로 범위를 나누고, 파일 SHA-256과 제목·설명·공개 범위의 입력 지문을 비교한다. 키 형식·길이와 보관 기간은 구현 시 DB 제약 및 API 오류 형식과 함께 확정한다.

| 조건 | 목표 응답 | 목표 DB·저장소 상태 |
| --- | --- | --- |
| 첫 요청 성공 | HTTP 201, 생성된 문서·버전·Job ID | 완료 원장과 문서·버전·Outbox·Job을 같은 DB 트랜잭션에서 확정 |
| 같은 사용자·키·입력으로 완료 후 재전송 | 최초 성공과 동일한 HTTP 결과 및 ID | 추가 문서·버전·Job 없음 |
| 같은 키지만 파일 또는 메타데이터가 다름 | HTTP 409 | 기존 완료 결과를 바꾸지 않음 |
| 같은 키·입력으로 이전 시도 진행 중 | 재시도 가능 시점을 알리는 응답. 상태 코드와 오류 코드는 구현 시 확정 | 동시 처리 소유권 한 시도만 유지 |
| 저장소 기록 뒤 DB 기록 전 중단 | 즉시 완료로 간주하지 않음 | 후보의 소유 시도·위치·해시를 추적하고 안전하게 재점유 또는 정리 |

```text
목표: 같은 키의 두 요청
  요청 A ─┐
         ├─ DB 유일 제약·처리 소유권 → 한 시도만 저장소/DB 작업 수행
  요청 B ─┘                         └─ 완료되면 원래 결과 재사용

  같은 키 + 다른 입력 지문 → 409 충돌
  완료 원장과 문서 생성은 동일 트랜잭션 → 커밋 결과와 재전송 판단이 함께 남음
```

저장소 후보 복구·generation 조건부 삭제는 별도 변경에서 다룬다. 요청 멱등성만으로 비동기 복제 중 이미 성공 응답한 커밋의 보존을 보장하지는 않는다. 그 경우는 별도의 RPO 시험 대상이다.
