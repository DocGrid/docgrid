## 배경

- 2차 평가(기능테스트·라이선스 검증, 10/12~10/28)는 저장소 상태를 기준으로 진행되고, 11/4에는 발표가 있다.
- `docs/test-results`에는 OpenSQL 3노드 장애, 권한 회수 복제 지연, 하이브리드 검색 품질, DB·GCS 시점 복원, 인덱싱 성능의 실행별 기록이 있다. 그러나 README 앞부분의 「관측 구성과 검증 범위」는 실행 기록 3개만 링크한다.

- 시연 영상 4개를 촬영했지만 README에서 찾을 수 없다.

### 검증된 범위: 선별 기준

표가 길면 앞부분에서 읽히지 않으므로 **가치가 높은 9개 행**만 넣었다. 기준은 다음과 같다.

1. 장애 전환·권한·검색 품질·복원·성능에서 영역마다 대표 결과를 하나 이상 둔다.
2. 같은 영역에서는 장애가 더 크거나 요청 수가 더 많은 실행을 고른다.
3. 실패와 한계는 행마다 별도 열에 원문 그대로 남긴다.

| 넣은 행 | 근거 문서 | 확인한 원문 위치 |
|---|---|---|
| OpenProxy 한쪽 중단 | `gimin-391-openproxy-ab-fault-load-20261003.md` | 172~173행 `ha391fa20001`·`ha391fb20001` 표, 3행 앞선 실행 A 0건·B 10건. 실행 시각은 `evidence/issue-391/ha391fa20001/실행-기록.md` 6행(2026-10-03 KST) |
| 계획 switchover | `issue-412-opensql-switchover-vu-telemetry-20261004.md` | 5행 실행 시각, 64행 `ha412sw400c`, 93행 최대 201 공백 6.204초 |
| 리더 VM 즉시 상실 | `opensql-primary-unplanned-fault-load-20261004.md` | 3행 실행일, 8행·53행 `ha420vm00001`. 자동 재시작 가드 실패는 통합 보고서 106·111행 |

### 넣지 않은 항목과 이유

| 항목 | 이유 |
|---|---|
| postmaster SIGKILL (`ha420proc001`) | 같은 문서의 리더 VM 상실이 더 큰 장애다. 아래쪽 「OpenSQL 핵심 부하·장애 검증」 표에 이미 있고, 표 아래 문단에서 이 절로 안내한다 |
| 동기 standby 링크 차단 (`sync433fault01`, `ha435fault01`) | 표 아래 문단에서 통합 보고서로 안내한다. 이 실행의 HTTP 500·503은 표 아래 문단의 "장애 중 HTTP 500·503과 결과 불명이 실제로 발생" 문장에 포함된다 |
| 정상 HTTP 쓰기 기준선, Patroni 재합류 | 장애·복원 결과가 아니라 기준선이다. 아래쪽 OpenSQL 표에 이미 있다 |
| Worker 수평 확장 (`gimin-#138`) | TXT 6,400자 부하라 PDF·DOCX E2E와 조건이 다르다. 한 행에 같이 쓰면 비교로 읽힐 수 있다. 성능 행의 링크(`#145`)에서 이어서 볼 수 있다 |
| 복원본 서비스 경로 (`db-gcs-service-recovery-20261015`) | 실제 BGE-M3·Ollama 없이 고정 벡터 스텁으로 일부 경로만 확인했다. 수치를 따로 행으로 올리지 않고 시점 복원 행의 한계 열에서 링크한다 |

### 작성 규칙

- 각 행에 측정 조건(부하, 실행 ID나 횟수, 날짜)과 출처 링크를 붙인다.
- 표 위에 "실행별 관측값이며 보장이 아님"과 판정 방식(요청 원장 `request_id` ↔ 최종 primary DB 행 대조)을 적는다.
- 표 아래에 장애 중 HTTP 500·503과 결과 불명 발생, 무중단 가용성·모든 장애의 RPO 0 미입증을 적는다.
- 조건이 다른 수치를 합산하거나 비교하지 않는다. 하이브리드 검색의 111문항 합계는 원문 표의 합계 행을 그대로 옮긴 값이다.
- 원문에 없는 해석은 덧붙이지 않는다. 22ms·105ms, 52.9초 같은 시간 값은 원문이 RTO로 해석하지 말라고 적어 두었으므로 앞부분 표에 넣지 않았다.
- 통합 보고서 159행에 따라 "장애를 견디는 구성"과 "무중단·무손실 보장"을 한 문장에 쓰지 않는다.
